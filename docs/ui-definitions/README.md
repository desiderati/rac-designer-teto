# Definições de UI

Este diretório reúne definições duráveis de comportamento visual para superfícies do RAC Designer
TETO.

Use estas definições quando uma decisão de interface precisar sobreviver à implementação pontual,
especialmente em telas operacionais, tabelas, cards, formulários e exportações para PDF.

## Índice

- [UI-001 - Texto, Overflow e Áreas Impressas](UI-001-texto-overflow-e-areas-impressas.md)
    - Define validação de textos em áreas dimensionadas e tratamento obrigatório de overflow.

- [UI-002 - Tabelas e Largura Proporcional de Colunas](UI-002-tabelas-largura-proporcional-colunas.md)
    - Define proporção de colunas em tabelas a partir do tamanho máximo dos campos exibidos.

- [UI-003 - Ações Responsivas de Formulários](UI-003-acoes-responsivas-de-formularios.md)
    - Define layout e posicionamento da ação principal nos quatro formulários do gerenciador.

- [UI-004 — Identidade visual e comportamento dos Toasts](UI-004-avisos-e-progresso-pdf.md)
    - Define anatomia, cores, ações, responsividade e reutilização de mensagens, tarefas PDF e imagem 3D.

- [UI-005 — Menus laterais do Canvas](UI-005-menus-laterais-canvas.md)
    - Consolida rótulos, navegação radial, compactação por altura, editores de pilotis/terreno e
      responsabilidades compartilhadas, sem alterar a política nativa dos gestos mobile.


- [UI-006 - Editores flutuantes e teclado no mobile](UI-006-editores-flutuantes-e-teclado-mobile.md)
    - Define foco, viewport visual, rolagem e acesso às ações com teclado em tela baixa.

- [UI-007 — Modais e ações compartilhadas](UI-007-modais-e-acoes-compartilhadas.md)
    - Define as regiões de rolagem, cabeçalhos, recuos, ações em 460 px e exceções das famílias
      consolidadas na R48.

- [UI-008 — Análise de Campo](UI-008-analise-de-campo.md)
    - Define planta expansível, editor inline por largura do card, nível sem quebra e critérios
      de paridade com o comportamento nativo.
